# Audit qualité des adresses MEL

Ce projet présente une analyse de la qualité des données d’adresses de la Métropole Européenne de Lille (MEL).

L’analyse porte notamment sur :

* les valeurs manquantes ;
* les doublons ;
* la validité et la cohérence des données ;
* la comparaison du nombre d’adresses avec la Base Adresse Nationale (BAN).

Les résultats permettent d’identifier les écarts entre les deux sources et les données nécessitant une vérification.
